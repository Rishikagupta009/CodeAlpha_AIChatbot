# Task 3 - Artificial Intelligence Chatbot

## Project Description

This project is a Java-based Artificial Intelligence Chatbot.

The chatbot allows users to communicate with it through a graphical user interface (GUI).

It uses basic Natural Language Processing (NLP) techniques and rule-based logic to understand user messages and provide suitable responses.

## Features

- Java-based chatbot
- Graphical User Interface using Java Swing
- Basic NLP text preprocessing
- Rule-based responses
- Interactive communication
- Send button
- Enter key support
- Answers questions about Java, AI, NLP and programming

## Technologies Used

- Java
- Java Swing
- Basic NLP techniques
- Rule-based Artificial Intelligence

## How to Run

1. Open the project folder in VS Code.

2. Open the terminal.

3. Compile the program:

```bash
javac AIChatbot.java
